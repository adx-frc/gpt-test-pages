Network / HTTP troubleshooting

DevTools → Network/Console (filter gpt/doubleclick).

Raw HTTP ad-server response: DevTools → Network → filter gampad/ads.

  • HTTP 200: request succeeded at HTTP level; GAM may still return an ad or blank response.
  • HTTP 204: request succeeded but no ad content was returned.
  • HTTP 4xx: request/config/access problem.
  • HTTP 5xx: server/infrastructure problem.
  • HTTP 302/307: redirect; follow redirect chain.

HTTP status cannot be inferred from GPT events. Check the actual ad request in DevTools.
